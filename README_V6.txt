PADEL ARENA MANAGER 6.0 - GESTIONE RICHIESTE ROSE

1. Carica tutti i file del pacchetto nel repository GitHub Pages.
2. Esegui una sola volta SUPABASE_AICS_2027_CAPITANI.sql nel SQL Editor di Supabase.
3. Admin: Campionato > apri squadra > sezione Rosa giocatori.
4. Capitano: accede dal proprio link e vede richieste in attesa, con Approva/Rifiuta.
5. Una richiesta rifiutata può essere compilata nuovamente con la stessa email.

Le notifiche sono interne all’app: il contatore appare nella sezione rosa quando la pagina viene aperta/aggiornata. Non vengono inviati automaticamente SMS, WhatsApp o email esterne.
