PADEL ARENA MANAGER 7.2 - ASTE MULTIPLE

NOVITA
- In creazione di un Rodeo a gettoni puoi scegliere da 1 a 4 aste.
- Ogni asta appare come scheda separata nel torneo.
- Il saldo disponibile viene aggiornato dopo ogni asta.
- I gettoni spesi vengono sommati automaticamente in Situazione gettoni.
- Con una sola asta, semifinali e finale restano gestibili nella stessa fase.
- I tornei già esistenti vengono considerati automaticamente con 2 aste.

INSTALLAZIONE
1. Sostituire tutti i file su GitHub Pages, incluso service-worker.js.
2. Per questa funzione non è necessario eseguire SQL.
3. Il file SQL completo V7.2 è comunque incluso per eventuali reinstallazioni complete.
