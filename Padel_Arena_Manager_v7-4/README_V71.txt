PADEL ARENA MANAGER 7.1 - SINCRONIZZAZIONE SUPABASE

1. Carica tutti i file del pacchetto nel repository GitHub Pages, sostituendo quelli esistenti.
2. In Supabase apri SQL Editor > New query.
3. Copia e incolla tutto il contenuto di SUPABASE_SYNC_V71.sql e premi Run.
4. Chiudi Safari, riapri l'app e accedi come amministratore.
5. In alto deve comparire: ADMIN · Francesco · SUPABASE CONNESSO.

I tornei e i giocatori vengono letti da Supabase all'accesso e aggiornati automaticamente.
